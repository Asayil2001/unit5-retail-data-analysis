# Unit 5 – Data Analytics with Python

## Overview
This activity analyses the Online Retail dataset using Python, Pandas, and Matplotlib.

## Notebook
[View the Unit 5 Retail Analysis](Unit5_Retail_Analysis.ipynb)

## Key Activities
- Data cleaning and validation
- Descriptive statistics of retail sales
- Visualisation of sales by country and month
- Reflection on SQL and NoSQL data storage

## Key Findings

| Metric | Result |
|---|---:|
| Original records | 541,909 |
| Cleaned records | 524,878 |
| Missing product descriptions | 1,454 |
| Duplicate records identified | 5,268 |
| Total sales | 10,642,110.80 |
| Average sale | 20.28 |
| Median sale | 9.92 |
| Countries represented | 38 |

The United Kingdom accounted for the largest share of sales in the dataset.
